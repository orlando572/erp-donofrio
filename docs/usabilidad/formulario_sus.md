# Cuestionario SUS (System Usability Scale)

Se responde al terminar las cuatro tareas. Escala de 1 a 5: **1** = muy en desacuerdo, **5** = muy de acuerdo. El sistema es el ERP de D'Onofrio (Odoo) que se acaba de probar.

| # | Enunciado |
|---|---|
| 1 | Creo que me gustaría usar este sistema con frecuencia. |
| 2 | Encontré el sistema innecesariamente complejo. |
| 3 | Pensé que el sistema era fácil de usar. |
| 4 | Creo que necesitaría el apoyo de una persona con conocimientos técnicos para poder usar este sistema. |
| 5 | Encontré que las diversas funciones del sistema estaban bien integradas. |
| 6 | Pensé que había demasiada inconsistencia en este sistema. |
| 7 | Imagino que la mayoría de las personas aprendería a usar este sistema muy rápidamente. |
| 8 | Encontré el sistema muy incómodo de usar. |
| 9 | Me sentí muy seguro/a usando el sistema. |
| 10 | Necesité aprender muchas cosas antes de poder empezar a usar el sistema. |

Las preguntas **impares** son positivas y las **pares** son negativas: por eso el cálculo les da vuelta (ver el plan de pruebas).

## Datos de la persona (sin nombre)

- Código: P1 a P5.
- Edad.
- Experiencia con sistemas de gestión: ninguna · poca · media · mucha.
- ¿Usa el computador a diario? sí · no.

## Pregunta abierta (opcional)

¿Qué fue lo que más le costó o le confundió?
