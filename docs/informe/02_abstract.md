## Abstract

This paper describes an academic enterprise resource planning (ERP) system for D'Onofrio, a fictitious ice cream and confectionery company; all company data are invented. The system is built on Odoo 19 Community and PostgreSQL 16, running in Docker containers, and was developed with Scrum under PMBOK practices in two phases separated by a checkpoint (Gate 0): a guaranteed core, and optional custom modules. The core covers the five business areas of the case (sales, street-vendor sales, production, warehousing with expiry control, and purchasing) using standard Odoo, configured entirely through code in a single module, `donofrio_base`. It also provides a PostgreSQL streaming replica, automated backups, and a hardened deployment behind Nginx with TLS, two-factor authentication for privileged users, and an audit log. The results are verifiable in the repository. All 136 automated tests, including unit, integration and security tests, pass, and a continuous integration pipeline runs them on every pull request. A restore from backup was measured at 31 seconds against a two-hour recovery target. Under a k6 load test with 20 virtual users, the 95th-percentile response time was 11.6 ms for lists and 9.1 ms for forms, against a limit of 2 s. An OWASP ZAP baseline scan reports no high-risk alerts, and Lighthouse shows the dashboard score rising from 45 to 80 after the Nginx deployment. The custom Phase 2 modules (quality, street vendors, cold chain, dashboard) are designed but not implemented, and are left as future work. Measurements come from a single machine with demonstration data.

**Keywords:** Odoo 19; ERP; PostgreSQL; Scrum; Docker.
